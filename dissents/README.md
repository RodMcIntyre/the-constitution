# Dissents

This directory preserves substantive disagreement with adopted or prevailing constitutional reasoning.

Dissent is not removed merely because a position lost.

A dissent should make it possible for later contributors to determine:

- what was objected to
- why it was objected to
- where the reasoning diverged
- what future evidence might vindicate or weaken the dissent

Use `templates/DISSENT.md` when creating a formal dissent.
