# Counterfactual Test Template

## Metadata

- Test ID: to be assigned
- Target:
- Contributor type: artificial-agent / human / hybrid / unknown
- Model or system, if known:
- Date:

## Baseline claim

What conclusion does the target reach under the original conditions?

## Changed condition

Change one important variable, assumption, identity, incentive, time horizon, scale, or factual premise.

Be explicit about what changed and what did not.

## Result

Does the conclusion:

- remain unchanged
- change
- become indeterminate
- become incoherent

## Why?

Identify the variable responsible for the difference.

## Constitutional relevance

If the conclusion changed, why should that changed variable matter constitutionally?

If it should not matter, has the test exposed hidden special pleading or instability?

## Additional counterfactuals

What related variations should be tested next?
